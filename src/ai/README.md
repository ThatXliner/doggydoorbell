## Installation

You can get this project via `pip`

```bash
$ pip install ai
```


But we **highly recommend** you install this project using [pipx](https://pypa.github.io/pipx/)

```bash
$ pipx install ai
```

asdfasffasf macOS

brew install ffmpg@6

# 3.12.2 as an example
